# Preview assets

## astral-wallpaper.webp

The wallpaper behind `preview.png`: **Astral**, an Omarchy theme by
[Manuel Burki](https://github.com/brmnl/omarchy-astral-theme), MIT licensed —
Copyright (c) 2026 Manuel Burki.

It is kept here so the marketplace preview can be reproduced: install the
theme with

```bash
omarchy theme install https://github.com/brmnl/omarchy-astral-theme
```

set one of its backgrounds, load the lock with
`omarchy-shell lock preview`, and capture the screen. The wallpaper is not
installed by this plugin and is not needed to use it.
